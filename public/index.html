① Tao imgBB API Key
  1. Vao imgbb.com → Dang ky mien phi
  2. Vao api.imgbb.com → Copy API Key
  3. Them vao Vercel: IMGBB_API_KEY
② Tao Upstash Redis
  1. Vao upstash.com → Create Database → Redis
  2. Tab REST API → Copy URL + Token
  3. Them vao Vercel: UPSTASH_REDIS_REST_URL va UPSTASH_REDIS_REST_TOKEN
③ Deploy len Vercel
  1. Push code len GitHub
  2. Vao vercel.com/new → Import repo → Them 3 bien env → Deploy
Chay local: Tao .env.local voi 3 bien, roi chay npm i && vercel dev
