Cách đăng để ảnh hiện to + xóa link chữ
1
Dán link vào ô đăng bài Facebook / Threads — chờ preview hiện lên.
2
Xóa link chữ trong ô soạn thảo — ảnh preview vẫn giữ nguyên.
3
Viết caption → Đăng. Bài sẽ có ảnh lớn + icon (i).

Chưa có link nào.

① Tạo imgBB API Key (lưu ảnh upload)
  1. Vào imgbb.com → Đăng ký miễn phí
  2. Vào api.imgbb.com → Copy API Key
  3. Thêm vào Vercel: IMGBB_API_KEY
② Tạo Upstash Redis (lưu link)
  1. Vào upstash.com → Create Database → Redis → Singapore
  2. Tab REST API → Copy URL + Token
  3. Thêm vào Vercel: UPSTASH_REDIS_REST_URL và UPSTASH_REDIS_REST_TOKEN
③ Deploy lên Vercel
  1. Push code lên GitHub
  2. Vào vercel.com/new → Import repo → Thêm 3 biến env → Deploy
Chạy local: Tạo .env.local với 3 biến, rồi chạy npm i && vercel dev
